# 《霸王三国志》ROM 寄存器间接调用离线审计报告

## 检查对象与可重复性

- 标准 BIN 大小：1,048,576 bytes
- 标准 BIN SHA256：`e70f0a92c205ea432080cc48c18d1d43b7fc4d45464ed7fb218b119096e7cdd9`
- 实际执行：本次通过本地 Python 分析程序重新读取 ROM，对字节指针、候选 Motorola 68000 指令入口做了检查；没有运行游戏模拟器、macOS/iOS 运行器或原生生成 C 代码。
- 输入：已存在的保守静态 CFG 根与 28 处 PC 相对跳转表分析结果。
- 注意：附带 68000 解码器是实验性子集解码器，图像/数据误分类、跳转目标遗漏均有可能。

### 具备进一步核对价值的 ROM 指针表

- `$000C1C JSR(A4)` 从 `$000C26` 附近的指针数组分发，候选目标含 `$000388/$0003A2/$000440/$000450/$00045A/$000512/$000580/$0005B0` 等。
- `$00C10E JSR(A0)` 的指针表 `$0455E8` 包含 `$00B54E/$00D4E4/$00D570/$041D12/$041D0E`。
- `$00DE9E JSR(A0)` 从两个地址 `$045A0C/$045A10` 取指针，值分别是 `$003672/$003664`。
- `$0213B0 JSR(A0)` 使用 `$045D56` 指针表，候选目标含 `$01FC7C/$01FED6/$01FF04/$020326/$0215F4`，可能影响部分内政/菜单路径，**仍需动态验证**。
- `$022A08 JSR(A0)` 使用 `$045DA6` 指针表，候选目标含 `$02295A/$0226CA/$02213E/$021F98`，其他多个相关调用点共享相邻表数据。
- `$035D5E JSR(A0)` 的表 `$0465D0` 含 `$035736/$035AA2/$035B22/$035C24/$043498/$043490`。
- `$03C30C JSR(A0)` 的表 `$046D7A` 含 `$03C0D0/$03C16E/$03BD8E/$03BFB8`。

表扫描最多检查每处 40 个槽，且以看似合法的指令解码作为一个筛选条件；既可能漏掉更长或稀疏的表，也可能将恰好能解码的数据误认成代码。切勿盲目把全部 142 地址加入 `late_extra`。

## 当前环境限制

本地容器为 Linux x86_64，无 Xcode，也无法从容器直接连接 `github.com` 进行 `git clone`。因此不能在这里执行现有 macOS Mach-O 原生运行器，也不能进行 iPhone/IPA 实机测试。本报告不包含任何真实游戏回合、AI 决策、画面校验或原生/解释器动态比较结果。

## 复现本轮离线审计

```bash
python3 bawang_pointer_table_audit.py \
  --rom /path/to/bawang_sanguozhi.bin \
  --base-report bawang_rom_static_probe.json \
  --switch-report bawang_iterative_switch_report.json \
  --csv bawang_indirect_pointer_targets.csv \
  --json bawang_pointer_audit_summary.json
```

需要将脚本和 JSON/CSV 放在与 `md68k_probe.py` 同一目录。压缩包不包括 ROM。
