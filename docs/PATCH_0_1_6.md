# 霸王三国志 0.1.5 Build13 → 0.1.6 Build14 增量补丁

## 本次实际修改

- **方向键对称布局**：3×3 十字位置（中心留空），上/下和左/右距中心一致；保留上一版的 52–68pt 自适应按键大小；透明度从 43% 深灰背景降至 31%（按住仍橙色）。
- **旗帜变黑的显示保护（实验性）**：弃用原来需要 43/64 亮像素同时变黑的无效判断，换成按 8×8 实际像素监测彩色旗帜的历史健康内容。只在黄色地图中，曾见到彩色图案、后来突然变暗时恢复。地图切走时清空历史，新颜色旗帜不会套旧颜色。**这不是 VDP 底层根因修复，且只有先见过彩色旗帜时才有效。**
- **简体“劉備→刘备”实验改进**：原版低分辨率字形 iOS OCR 不稳定。现允许玩家在“显示设置→从当前游戏画面校准『劉備』字形”中框选真正的原版两个汉字，保存其像素模板，以后在同样背景和字形下精确定位并覆盖简体点阵。保留 OCR 作为未校准时的备选。只处理该词，不能承诺其他汉字、全部位置均可转换。
- **其他**：保留此前已经好用的画面放大、Metal 三缓冲、章节过渡保护、ROM 内置、手柄输入和 SRAM；版本统一调整到 0.1.6 Build14，Actions 仍仅手动触发。

## 真机验证顺序

1. 保留并覆盖安装旧 App（Bundle ID 未变），避免删 App 导致 SRAM 丢失。
2. 测试方向键上下左右、长按、双指按方向+A；现在采用真正对称的 3×3 布局。
3. 先到旗帜**正常有颜色**的地图，再触发马动画。进入齿轮设置，可以对比开关“保护地图已显示的彩色旗帜”。如果开关都发黑，需要保存该动作前后的录屏，以便定位 VDP 根因。
4. 切换简体模式，让屏幕上显示实际的繁体“劉備”；打开齿轮→“从当前游戏画面校准『劉備』字形”，框选整个两字（建议包含两字字体区域约 32×16 像素，紧贴外边缘），点击保存；关闭设置查看文字是否变化。如果显示“未识别”，检查模板选区背景是否纯色；不同字体/调色板可能需要重新校准。
5. 章节选取后瞬间乱码仍可独立关闭补偿，以便后续和参考 VDP 对照。
