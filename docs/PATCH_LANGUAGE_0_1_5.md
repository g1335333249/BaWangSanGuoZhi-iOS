# 《霸王三国志》iOS 0.1.5 Build 13：移除 ROM 导入 UI + “刘备”简体试验

**基线：已经应用上一份 `0.1.4 Build 12` 显示整合补丁。** 与原始 `548183a` 基线适配的完整叠加补丁也会一起提供。请按自己本地代码状态选其中一个，不要两个同时应用。

## 具体变更

1. `BawangApp.swift` 删除右上角 `folder.badge.plus` 文件夹导入按钮、文件选择器以及游戏未启动时的 ROM 导入按钮。唯一保留的右上角入口是齿轮设置。没有内置 ROM 时明确提示需安装包含游戏资源的 IPA。**不会删除 `GameSession` 的原有底层 ROM 读取与校验逻辑**；App 照旧从之前已校验的沙盒 ROM 或 IPA 内置 ROM 启动。
2. 设置新增 `繁体原版` / `简体 · 刘备测试` 两个选项及可见的文字示例；设置持久化在 `UserDefaults`。切换不改游戏状态/存档。
3. `GameTextLocalization.swift` 是**有限的实验性显示替换**：每 45 帧以设备自带 Vision 在后台尝试识别精确字符串 `劉備`，只对识别区域使用内置的 16×16 简体点阵替换为 `刘备`；要求原画面的该区域在识别与显示时字节指纹一致，且文字背景接近单色，否则保持原样。无需下载中文字体、无网络请求。不修改 ROM、SRAM、原生重编译 C 代码或游戏字体编码。
4. 设置显示「最近一次游戏画面识别」结果。**如果没有出现替换**，请先看它是否显示「找到劉備」。Vision 可能在 256/320×224 低分辨率中文像素字体上无法识别，或某些 iOS 版本不支持 `zh-Hant` 识别，这不是转换全字库的方法，也不代表游戏原文编码可以直接转换。
5. App 版本 0.1.5 / Build 13，GitHub Actions 仍只有手动 `workflow_dispatch`，IPA 名称/验证同步。不会清除 `Library/Application Support/BawangSanguozhi/bawang.srm`。

## 修复边界

- 本补丁实现可切换 UI 和**只尝试识别一个词**的显示层试验。它不会保证游戏中所有的「劉備」出现都能被替换，不能证明已经找到了 ROM 原始中文字库。
- 不会影响原有 0.1.4 的暂时乱码/马动画黑块显示补偿，也没有改变它们的 VDP 处理根因。
- 补丁合入项目后，iphoneos ARM64 Release 无签名 Xcode 构建、纯 Swift 点阵替换/防过期测试，以及带内置 ROM 的 IPA 校验均通过。尚未进行真机 OCR 验证。

提交并推送后手动运行 GitHub Actions IPA 构建。升级 IPA 应使用兼容的签名身份与相同 Bundle ID 覆盖安装；不要卸载旧版，以免丢失游戏存档。

## 测试方法

1. 打开新版，确认右上角只有齿轮图标（无 ROM 导入文件夹）。
2. 进入设置，繁体时示例为 `劉備`，简体时为 `刘备`。
3. 在游戏进入能够显示 `劉備` 的界面并停留 2-3 秒，检查简体替换。再切回繁体，游戏应恢复原始文字。
4. 如果没有替换，记录「最近一次游戏画面识别」的状态，并给出该场景真机截图，以便下一轮基于真实字形做确定性字库方案。
5. 检查此前章节选择、地图骑马黑块、虚拟按键、SRAM 保存与恢复没有回退。
